## ✨ What's New

- Added the option to move your OpenWiki data (saved items and images) to another location, such as an external drive: Settings → Storage → Data Location
- After moving, your original data is kept until you choose to delete it in Settings
- If your data is on an external drive that isn't connected when OpenWiki starts, you'll be asked to connect it instead of starting with an empty library

## ✨ 本次更新

- 新增「数据存放位置」：可以把 OpenWiki 的数据（收藏内容和图片）搬到其他位置，比如外接硬盘（设置 → 存储）
- 搬好后原来的数据会先保留，确认没问题再在设置里删除
- 数据放在外接硬盘上时，如果启动时硬盘没连接，会提示先连接硬盘，不会打开一个空的收藏库

## 安装说明 / Installation

### 🪟 Windows

1. 点上面的「下载 Windows 版」，下载 `OpenWiki_0.3.30_x64-setup.exe`。
2. 双击运行。若弹出「Windows 已保护你的电脑」蓝色提示，点 **更多信息 → 仍要运行**（本程序暂未做 Windows 代码签名，这是正常提示，文件是安全的）。
3. 按提示完成安装。打开后进入 **设置 → AI**，填入 AI 服务商的 API Key（Claude / OpenAI / Gemini）。

### 🍎 macOS

1. 按你的芯片，点上面对应的下载链接。
2. 双击 `.dmg`，将 **OpenWiki** 拖入 **Applications**（应用程序）文件夹，覆盖旧版本。
3. 双击 OpenWiki 即可打开（已做 Apple 签名 + 公证，不会被拦截）。
4. 打开后进入 **设置 → AI**，填入 AI 服务商的 API Key（Claude / OpenAI / Gemini）。
