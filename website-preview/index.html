存进去之后

摘要和标签，不用你自己写。

复制链接会自动去读网页正文；截图会自动识别里面的文字；存下来的内容会被写成一句话摘要，再打上几个标签，以后按标签就能翻回来。

  • 知乎、微信公众号这类需要渲染的页面，用内置浏览器真实打开再读
  • 外文内容可以自动翻译成中文
  • 反复复制同一段话会自动合并，只留最完整的那条

为什么值得看

你最近收藏了 5 条和「专注」有关的内容，这条把原因讲得最清楚，适合先看它。

收藏最难的一步：回看

过几天，它主动来找你。

收藏夹的老问题是存完就忘。OpenWiki 会从你存的东西里挑出值得再看一遍的，过几天在屏幕右上角弹一张卡片，并且告诉你它为什么挑中这条。

  • 点「已学习」就不再提醒；点「下次再说」会过几天再来
  • 最多提醒 3 次，之后安静地留在「待学习」里等你
  • 鼠标停在卡片上时倒计时会暂停，读完再说

左边的卡片可以点，试试三个按钮

能接住什么

只要能复制，它就能接住。

文字

句子、代码、聊天里的一段话。密码和 API Key 会被自动过滤，不会存进去。

截图

截完自动识别图里的文字，以后搜图片里的内容也搜得到。

链接

复制网址就自动去读正文，存下来的是文章本身，不是一个以后打不开的链接。

文件

PDF、Word、PPT 拖进来会转成文字存下。想随手记点什么，按 ⌘⇧C 直接写。

数据在哪

在你自己的电脑上。

OpenWiki 不做账号，也没有服务器替你保管内容。所有收藏存在本机的一个数据库文件里。

  • 只存你点了保存的

    没点的内容不会留下任何记录，剪贴板里其它东西也不会被悄悄收走。

  • AI 用你自己的 Key

    在设置里填 Claude、OpenAI 或 Gemini 的 API Key，用哪家、花多少钱都由你决定。

  • 密码自动挡掉

    识别到密码、私钥、API Key 这类内容时，浮窗不会弹出来。

常见问题

你可能想先问的几件事。

它跟剪贴板管理工具有什么不一样？

剪贴板工具保存你复制过的每一条，目的是让你能粘回去。OpenWiki 只保存你点了保存的那些，目的是让你几天后还能想起来——所以它会写摘要、打标签，还会主动提醒你回看。

必须填 API Key 才能用吗？

收藏、搜索、看内容都不需要。摘要、标签、学习提醒这些要用 AI 的功能，需要在「设置 → AI」里填一个 API Key。

Windows 版功能一样吗？

收藏、AI 摘要、学习提醒都一样。足球悬浮球目前只在 macOS 上提供。另外 Windows 版还没做代码签名，安装时系统会提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可。

会一直在后台偷偷记东西吗？

它需要监听剪贴板变化才能在你复制时弹出浮窗，但只有你点了保存的内容才会写进数据库。内容捕获也可以在设置里随时关掉。

怎么更新？

有新版时会在后台下载，下载完在右下角问你要不要现在安装。设置页里也能看到当前版本和下载进度。

下一次复制，就开始了。

装好，填一个 API Key，然后照常用电脑就行。剩下的事它自己做。
